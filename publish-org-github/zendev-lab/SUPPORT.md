# Support

This file routes requests. Project documentation stays in the project.

| You want | Go to |
| --- | --- |
| How Zendev works | [Zendev documentation](https://docs.zendev.zrr.dev/), and [zendev](https://github.com/zendev-lab/zendev) when you need the implementation |
| How Spark works | [Spark documentation](https://docs.spark.zrr.dev/), and [spark](https://github.com/zendev-lab/spark) |
| How Cue works | [cue](https://github.com/zendev-lab/cue) |
| A defect in a project | An issue on the repository that owns the behavior |
| A change whose owning tool is unclear | A discussion in the repository you believe owns it, naming the boundary with the other tools |
| This organization page, a broken link on it, or these default community files | An issue on [zendev-lab/.github](https://github.com/zendev-lab/.github/issues) |

Report security issues in private, using [SECURITY.md](./SECURITY.md).
