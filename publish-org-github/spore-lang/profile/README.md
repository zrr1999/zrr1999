# Spore

An experimental language for expressing intent, structure, and laws.

Spore is a compiled, general-purpose language. The function signature is where types, failure, effects, cost, and behavioral assertions are stated together. Holes make an unfinished implementation a normal, checkable state for people and agents working against the same constraints.

This page separates the language, its design process, and the toolchain. The language manual stays in the implementation repository and the docs site.

## Participate

Principles that apply across the organization are in [CONTRIBUTING.md](https://github.com/spore-lang/.github/blob/main/CONTRIBUTING.md). A project with its own contributing guide uses that guide.

An implementation that disagrees with behavior already specified is a defect in the implementation repository. A change to the language goes through [spore-evolution](https://github.com/spore-lang/spore-evolution). Routing for the other cases is in [SUPPORT.md](https://github.com/spore-lang/.github/blob/main/SUPPORT.md). Problems with this page belong in [this repository](https://github.com/spore-lang/.github/issues).
