# Support

This file routes requests. The language reference stays in the docs site and the implementation repository.

| You want | Go to |
| --- | --- |
| How to learn or use Spore | [spore-lang.dev](https://spore-lang.dev/) and [docs.spore-lang.dev](https://docs.spore-lang.dev/) |
| Current implementation behavior | [spore](https://github.com/spore-lang/spore) |
| The implementation disagrees with semantics that are already specified | A bug on the implementation repository. Link the document or accepted proposal that states the expected behavior |
| A change to what the language means | [spore-evolution](https://github.com/spore-lang/spore-evolution) |
| Command-line effects: files, processes, environment, standard I/O | [basic-cli](https://github.com/spore-lang/basic-cli) |
| The public websites | [spore-lang.dev repository](https://github.com/spore-lang/spore-lang.dev) |
| This organization page or these default community files | An issue on [spore-lang/.github](https://github.com/spore-lang/.github/issues) |

Keep those two language reports apart. One says the implementation missed a specified meaning. The other asks to change that meaning.

Report security issues in private, using [SECURITY.md](./SECURITY.md).
