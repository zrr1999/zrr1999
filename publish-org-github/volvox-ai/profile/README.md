# Volvox

Exploring composable foundations for deep learning.

Volvox is a research effort toward a framework for building deep-learning frameworks: where component boundaries sit, how dependency and execution semantics are stated, and which properties still have to hold after a component is replaced.

## Public stage

The work is exploratory. This page will link public write-ups and repositories when they can be read on their own. There is no public documentation site yet.

A short personal note is on [zrr.dev](https://zrr.dev).

## Participate

Principles for public work in this organization are in [CONTRIBUTING.md](https://github.com/volvox-ai/.github/blob/main/CONTRIBUTING.md). A published experiment needs to be reproducible. A numerical result or a performance claim needs the conditions under which it was measured.

Where to send a request is in [SUPPORT.md](https://github.com/volvox-ai/.github/blob/main/SUPPORT.md). Problems with this page belong in [this repository](https://github.com/volvox-ai/.github/issues).
