# Security

Report vulnerabilities in private, to an address a person actually reads. This policy sets the reporting path. It does not promise a response time or a disclosure schedule.

## A project in this organization

Use the project's own security policy when it has one. A `SECURITY.md` in the project replaces this file.

If the affected repository has no security policy, email [volvox@sixbones.dev](mailto:volvox@sixbones.dev). Include the repository name, the impact, the affected version or revision, and reproduction steps that are safe to share.

This file does not enable GitHub private vulnerability reporting. That setting is turned on per repository.

## This repository

This repository holds the organization profile and the default community files. Send problems in those files to [volvox@sixbones.dev](mailto:volvox@sixbones.dev) as well.
