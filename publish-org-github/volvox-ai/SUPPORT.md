# Support

This file routes requests. There is no public Volvox documentation site yet.

| You want | Go to |
| --- | --- |
| The public direction of the work | The [organization profile](https://github.com/volvox-ai) |
| A defect in a public repository | An issue on that repository |
| A numerical or performance result you cannot reproduce | An issue on the repository that published it, with the revision, command, and conditions |
| A proposal about framework design | There is no public design tracker yet. Discuss it on the public repository the proposal would change. File a bug when a published result fails under its stated conditions |
| This organization page or these default community files | An issue on [volvox-ai/.github](https://github.com/volvox-ai/.github/issues) |

Report security issues in private, using [SECURITY.md](./SECURITY.md).
